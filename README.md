# 小动物餐厅

给2～3岁孩子和照护者一起玩的离线 H5 小游戏。小兔子、小熊是餐厅客人，支持动物点餐、食物分类、自由厨房，以及父母逐句配音。

## 本机启动

需要 Node.js 20 或更新版本。应用没有第三方运行时依赖，不必安装 npm 包。

```bash
cd animal-restaurant
npm run build
npm start
```

打开 <http://127.0.0.1:4173>。默认音频和图标已包含在项目中。

首次访问需要等“已准备好，可以离线玩”。点击“开始玩”后有声音；右上角“家长区”长按3秒，再确认进入。

## 在 iPad / Android 平板上使用

1. 将 `public/` 的完整内容部署到支持 HTTPS 的静态站点，保持目录结构和同源访问。
2. iPad 用 Safari 打开，在分享菜单选择“添加到主屏幕”；Android 用 Chrome 打开，在菜单选择“安装应用”或“添加到主屏幕”。
3. 从桌面图标重新进入，联网完成资源准备，然后在这个入口录音或导入语音包。
4. 出现离线就绪提示后，断网检查能否开始游戏、听见声音和恢复录音。

正式网址：https://little-animal-kitchen.pages.dev/ 。已部署到 Cloudflare Pages。电脑上的 `127.0.0.1` 地址不能直接在平板使用；普通局域网 HTTP 地址也不满足麦克风和 Service Worker 的安全上下文要求。需要 HTTPS 或设备认可的本地 HTTPS 开发环境。

为保留独立的离线和录音数据，避免在微信等应用内嵌浏览器中使用。浏览器与桌面应用可能有独立存储；可通过语音包转移录音。

## 家长配音与备份

- 在家长区选择角色和台词，逐句录制、试听、保存，最长15秒。
- 默认提供204条本地中文音频；未录制台词使用对应角色默认声音。
- 父母录音在设备上转成22.05kHz、单声道、16位 PCM WAV，导出 JSON 语音包即可在另一台平板导入。
- 导入先校验全部音频，再显示替换确认；只替换同角色同台词，其余保留。失败不会写入已有录音。
- 录音不上传。清理浏览器数据会清掉录音和进度，请自行备份。
- 系统静音、媒体音量、浏览器权限仍由设备控制。游戏中没有背景音乐。

## 默认玩法

- 动物点餐：七种食物、数量1～5、完整图案提示，每次至多接待三位客人。每单锅内提供对应食物的准确份数，取走减少、拿回恢复，不自动补充。
- 分类：每轮从七种食材中随机选三种，每种两个，最多三轮；先点食物再点盘子，或直接拖入。
- 自由厨房：每位客人从七种食物中随机选择三种，每种准备两个，随意搭配，盘内最多五个，支持数数和请客。
- 单次默认五分钟，家长可选八或十分钟；到时温和收尾，没有无限续局按钮。
- 配置从下一次开局生效。切后台会暂停，返回需点击继续。

## 开发与验证

```bash
npm test
npm run build
```

浏览器验收使用 Playwright（开发依赖，应用不需要它）。先启动本机服务，再执行：

```bash
node tests/browser.mjs
```

若 Playwright 不在项目依赖中，可以设置 `PLAYWRIGHT_MODULE` 指向已安装的包；`CHROMIUM_PATH` 可指定本机浏览器。设置 `TEST_MIC=1` 使用 Chromium 虚拟音频设备验证录音，避免访问真实麦克风。测试截图和结果保存在 `artifacts/`。

默认音频仅在需要修改台词时重新生成，依赖 macOS `say` 和 `ffmpeg` / `ffprobe`：

```bash
npm run audio
npm run build
```

修改台词后需要删除对应旧音频再重新生成。生成器会验证输出有有效音频帧；构建也会拒绝明显无效的音频。音频来自本机系统合成语音，生成来源记录在 `public/assets/audio/provenance.json`。

每次修改 `public/` 后重新运行构建，以更新离线版本。已有用户会在家长区看到新版本入口；游戏中不自动刷新。

## 目录

- `public/js/model.js`：纯游戏状态转换，独立于界面和浏览器。
- `public/js/app.js`、`art.js`、`styles.css`：界面、触摸交互和本地矢量插画。
- `public/js/parents.js`、`audio.js`、`storage.js`：家长设置、音频、录音与备份。
- `public/js/offline.js`、`scripts/sw-template.js`：离线准备、音频 Range 支持和显式更新。
- `docs/README.md`：需求、设计、架构、决策、路线、验收和部署资料的统一入口。

自动化浏览器通过不等于 iPad / Android 真机通过；真实平板、真实麦克风、添加到桌面与儿童试用必须按验收清单检查。

食材更新：鸡翅已替换为排骨，使用“块”作为量词。旧会话自动保留数量和装盘位置；旧鸡翅配音保留在备份中，不会作为排骨语音播放。

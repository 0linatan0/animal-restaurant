## 真机验收清单（待完成）

在至少一台iPad及一台Android平板上分别检查：

- [ ] HTTPS访问，添加主屏幕，重新从桌面图标打开。
- [ ] 首次完整下载后，飞行模式下关闭并重新打开应用，三种模式可玩。
- [ ] 实际扬声器播放正常，切后台停止声音，返回主动继续。
- [ ] 真实麦克风授权、录制、15秒自动停止、试听、保存、重录、恢复默认。
- [ ] 取消授权仍能使用默认配音；取消录音、离开录音页、切后台后麦克风指示消失。
- [ ] iPad录音导出到Android可播放，反向亦然。
- [ ] 横竖屏、多指、拖动吸附和无效区域归位符合预期。
- [ ] 系统静音及低音量时，照护者能正常处理；没有重叠语音。
- [ ] 达到时长或轮次后自然收尾，无自动续局。
- [ ] 两档点餐、自动／手动核对、声音恢复和享用跳过可用；核对与享用中切后台／刷新后可继续，且不重复计轮。
- [ ] 检查真实设备型号和系统版本，记录为实际支持范围；尚未声称覆盖近两个主要版本的全部机型。

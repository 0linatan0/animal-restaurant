# 可复用的家人复刻语音包制作

用户已在火山引擎完成本人声音复刻并认可音色。本次把这个已有音色用于小兔子，后续可以把爸爸或其他已授权家人的音色分配给小熊。工具不负责采集声音或训练模型。

## 方案

采用电脑端 Node.js 命令行：读取游戏台词 → 调用豆包声音复刻 2.0 → 本地 WAV 和试听页 → 成人检查 → v1 JSON 语音包 → 游戏现有家长区确认导入。

相比控制台手工逐句下载，此方案能保持台词 ID、检查完整性并断点续跑。相比在 H5 中加入云生成入口，它不需要为儿童端引入网络服务、密钥或账号。

## 范围与接口

- 台词唯一来源是 `public/js/catalog.js` 的 `LINES`，当前每角色 106 句、885 个字符（本地统计，非计费承诺）；归档鸡翅台词不再生成。
- `profile` 表示一个音色及参数；`role` 表示游戏角色，两者独立。支持当前 `rabbit` 和 `bear`，新动物需游戏先增加角色，不能靠语音包创建。
- `plan` 离线盘点；`sample` 生成 15 句代表性样音；`generate` 生成全部或指定 ID；`pack --reviewed` 表示成人已试听，离线校验并封装。生成不直接改游戏 IndexedDB。
- 接口固定为火山官方 HTTPS 地址、资源 `seed-icl-2.0`。支持新版 API Key 或旧版 App ID / Access Token，凭据和 Speaker ID 只从环境变量取得。
- 使用原语速和 standard 模型作为初始值，不添加未验证的情感指令。生成 PCM 后封装为 24 kHz、16 bit、单声道 WAV，检查时长 0.15～15 秒及单条 base64/整包大小限制。
- 响应必须有成功终止码，截断、全静音或服务错误不能成为有效录音。顺序请求，失败即停止；已成功句子保留，重跑跳过有效缓存。默认不自动重试，避免模糊失败重复付费。
- 缓存按实际解析出的 Speaker ID 值、文本、模型、语速和格式的摘要隔离，并校验内容摘要，避免同 profile 换音色、改台词或中断后误用旧音频。支持单句强制重做；同音色 ID 云端重新训练时需显式强制生成。
- 包键为 `rabbit/台词ID` 或 `bear/台词ID`，沿用 `little-kitchen-voices` v1。缺少任何所选台词时拒绝打包。单角色包不会删除另一个角色录音。

## 数据、授权与删除

合成会把公开游戏台词、已复刻音色 ID 和鉴权请求发往火山引擎；不上传儿童资料、浏览器数据或原始训练录音。本人音色已获本次用户授权；爸爸等其他家人的音色待本人授权和配置后才生成。

本地凭据、WAV、缓存、试听页和语音包位于 Git 忽略的 `.voice-packs/` 或 `artifacts/voice-packs/`，不放入 `public/`，不随构建部署。日志不输出密钥、Speaker ID 或服务端原始错误文本。试听页使用本地内嵌音频，无外部脚本和网络请求。

本地文件可按制作目录删除；平板内录音通过恢复默认删除，语音包备份另外删除。云端已有音色和训练材料仍由本人在火山控制台管理，本工具不会删除或重新训练，也不声称本地删除会同步清除云端副本。平台保存策略以账户实际条款为准。

## 验收

自动测试覆盖流式分块、成功终止、错误/截断、WAV 边界、角色隔离、缓存恢复、修改失效、凭据不落盘、缺句拒绝及生成包在浏览器真实解码/导入。运行项目单元测试和构建。真实音色的发音自然度、单字数词、量词及平板播放由成人试听确认。

真实生成依赖用户提供本地凭据配置路径和已复刻 Speaker ID；无凭据时完成工具、清单和离线验证，不冒充已生成本人语音。

官方依据（2026-09-24 核对）：[HTTP Chunked / SSE V3](https://docs.volcengine.com/docs/DoubaoVoice/HTTPChunkedSSEUnidirectionalStreaming-V3?lang=zh)。

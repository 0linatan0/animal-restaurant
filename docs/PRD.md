# 《小动物餐厅》产品需求文档 V1.2

本文件记录当前已经确认并实施的产品需求。初版于2026-09-21确定，2026-09-23补充家庭双设备场景、点餐余量和上菜核对（本地实现，待发布）。面向2～3岁儿童，自家使用，成人在旁、孩子主操作。

需求背后的家庭场景和学习假设见[项目背景与共同认知](./PROJECT_CONTEXT.md)，具体界面规则见[产品与交互设计](./PRODUCT_DESIGN.md)。仍在评估的双设备自动同步和批量生成家人语音不属于本版本，见[产品路线](./ROADMAP.md)。

## 产品目的

通过厨房角色扮演将食物分类、数字、数量及一一对应计数联系起来。父母用熟悉的音色扮演小动物，而不是模拟父母在线聊天。产品不评估智力、能力或发展水平。

## 首版内容

| 内容 | 范围 |
| --- | --- |
| 角色 | 小兔子、小熊，交替接待 |
| 食物 | 水饺、大虾、排骨、西蓝花、青菜、香菇、包子 |
| 数量 | 1～5，可选1～3或指定一个数量 |
| 模式 | 动物点餐、食物分类、自由厨房 |
| 声音 | 完整内置音频，父母按角色逐句替换 |
| 平台 | iPad Safari、Android Chrome，可添加桌面，首次准备后离线运行 |
| 数据 | 无账号、无云同步、无上传，本机记录和录音包备份 |

不包含组合订单、算式、经营升级、广告内购、排行榜、连续奖励、声音克隆、语音识别、开放AI聊天。

家庭有两名孩子，预计使用两台平板。当前每台设备独立保存设置、会话和录音；家长在一台设备完成配音后，通过导出文件并在另一台导入来复制语音包。两台设备的游戏进度不合并。

## 页面

儿童首页只有一个主要开始按钮；家长区弱化。厨房保持单场景，动物和订单在上方，食材与盘子在操作区。收尾页无分数，不自动续局。

家长入口为长按3秒和文字确认，属于防误触机制，不是身份认证。支持键盘进入确认以保留可访问性。家长可调整模式、数量、提示和时长，跳过或结束，录制配音、备份、查看离线状态和最近一次记录。

## 游戏规则

### 动物点餐

1. 一次一种食物、一种数量；从所选范围随机生成，避免相邻完全相同订单。
2. 家长可选“一起装盘”（默认，库存等于订单）或“自己拿够”（目标1～3、同种食物多一份）。后者固定完整提示；从1～5、4或5切换时明确提示改为1～3。取走一个少一个，退回才增加，不自动补充。点击食物入盘，点击盘内食物退回，也支持拖动。
3. 盘子最多五个，食物互不遮挡。达到目标数量不自动上菜，由孩子点击提交。
4. 重听按钮重复当前订单。
5. 默认提示为数字＋目标份数图案＋语音；简化提示为数字＋一个种类图标＋语音。
6. 上菜后默认动物逐个数实际盘子；孩子可选择“我来数”或“帮我数”，切换时从一重数。数完报实际总量，再核对订单；不匹配先重申目标，再提示调整，保留盘子。空盘直接引导取食；第二次连续不匹配展开图案，不自动代答。
7. 不倒计时催单，不以动物生气、扣分或红叉惩罚错误。
8. 成人可跳过。每局最多接待三位客人，跳过也消耗当前客人位置。

### 数一数

数数模式与取放模式明确分开。数数时每个食物只能计数一次，重复点击不增加数量，按孩子动作逐个播放数词。全部点完确认总量；混合食物只确认个数，不宣称订单正确。退出后可改盘，再次进入重新计数。

### 上菜核对与享用

自动计数逐个指物并播放数词，食物不移动、不消失。手动计数按孩子点按推进，同一物体不能重复计数，当前数词结束前不接收下一次计数。核对期间停止取放、禁用重听；“继续装盘”取消核对并清空标记。数词、实际总量、目标和反馈分别完整播放，不机械拼词。

核对匹配后感谢，展示约3.6秒动物拿食物、咀嚼和享用画面，可跳过。数完才开始吃，减少动态效果时采用静态呈现。享用完成与跳过只能推进一轮，不自动开新局。自由厨房和分类保留原有完成流程。

任何核对语音失败都允许重播当前短句或无声继续，不能重复标记、卡住手动计数或跳过核对。核对中暂停／刷新后主动继续，从一重新数；享用中恢复只重放展示，不重新提交。收工提醒延至核对／享用结束；时间上限和家长结束立即生效。

### 食物分类

每轮从七种食物中随机选择三种，共六个食物，每种两个，随机位置。支持拖动，或先选食物再点对应图案盘子。放错则留在原位并温和提示，分完才进入下一轮。最多三轮，不显示分数、用时和错误次数。

### 自由厨房

每位客人从七种食物中随机选择三种，每种提供两个，取放时保持锅与盘子的总量不变；自由搭配，盘子最多五个，支持数数。点击请客后动物接受，不评价搭配，下一位客人入座时重新准备食材。不加入切菜、火候等额外操作。

## 时长与中断

单次默认五分钟，可选八或十分钟；这是产品设置，不是医学安全阈值。剩余约一分钟时提醒收工，不在儿童页显示数字倒计时。达到轮数或时间上限即收尾，无需做对才退出；未完成的盘子保留，不说成已完成。

切后台立即停止语音和计时，返回主动继续。刷新保留盘子、订单和提交阶段；已提交的订单不会重复计轮。家长设置下一次开局生效。

## 视觉和交互

薄荷绿餐厅、木色桌面、绘本小动物。横屏为主要布局，竖屏上下排布。核心触摸目标至少72×72 CSS像素，支持吸附和无效拖动归位。一次只处理一个指针。不用闪烁、震动或长庆祝动画；默认无背景音乐，语音期间不播放操作提示音。

## 配音

按角色提供入座、点餐、逐个计数、总量、引导、分类自由玩、感谢与结束台词。点餐覆盖七种食物×五个数量。

家长可逐句录制、试听、重录、保存、恢复默认，单句最长15秒。订单录完整句，不机械拼接词语。未录条目使用默认对应角色音频，家长区明确显示覆盖数量。

麦克风只在家长主动录音时打开，结束、取消、离开页面、切后台均释放。孩子端不监听。语音串行播放，换订单或退出时取消旧声音。支持试听完整订单。

父母录音转换为单声道 PCM WAV，备份包带版本和台词标识。导入先验证整包，用户确认替换，再通过单次 IndexedDB 事务写入。格式错误、音频损坏和保存失败不能破坏已有录音。

## 离线与更新

所有页面、SVG、默认音频和图标随应用缓存。完整缓存通过检查才显示离线就绪；初始化失败可重试。资源更新在独立临时缓存完成后提交，下载失败保留已有资源。家长主动更新，不在游戏中自动刷新。

正式部署需要HTTPS。首次音频由开始按钮解锁；被阻止时提供恢复入口。无法录音时仍可使用默认语音和导入。内嵌浏览器建议切换Safari/Chrome。本机存储可能被系统清理，需导出备份；不假设浏览器与桌面入口共享录音。

## 验收

规则测试覆盖35种订单、容量和计数去重、分类错误与完成、两次提示、暂停和计时、三轮收尾、恢复状态。浏览器验收覆盖真实DOM取放、拖动、三模式、录音模拟、备份验证、全部音频解码、离线新页面启动及横竖屏。

最终还需至少一台iPad和一台Android平板检查真实触摸、音频、麦克风、安装与断网启动，并进行三次短时家庭试用。观察孩子是否理解操作、需要何种提示、是否愿意听角色声音，以及是否能在成人帮助下自然收尾；不以全部答对为通过条件。
